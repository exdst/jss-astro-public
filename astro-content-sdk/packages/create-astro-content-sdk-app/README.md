# Astro Content SDK Initializer

`@exdst-sitecore-content-sdk/create-astro` scaffolds a ready-to-run [Astro](https://astro.build/) + SitecoreAI(XM Cloud) sample application built on [`@exdst-sitecore-content-sdk/astro`](../astro-content-sdk/). It is provided as part of the EXDST Astro Content SDK.

## How to use it

```bash
npx @exdst-sitecore-content-sdk/create-astro@latest
```

Follow the prompts and choose a starter template — for example **Alaris**, **Solterra & Co.**, or **Skate Park**.

## Why Astro

Astro renders to HTML by default and only hydrates the islands that need JavaScript, delivering higher Lighthouse scores on mobile, faster LCP, and less main-thread blocking versus Next.js with the Content SDK. See the [case study](https://exdst.com/case-studies/sitecore-astro-sdk).
